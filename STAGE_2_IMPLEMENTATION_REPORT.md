
### ✅ 3. Правило "Подозрительные паттерны" (SuspiciousPatternsRule)

**Новая функциональность:**
- ✅ Полностью новое правило с конфигурационным файлом
- ✅ Категоризация подозрительных слов по типам рисков
- ✅ Регистронезависимый поиск
- ✅ Настраиваемые режимы поиска (точное/частичное совпадение)
- ✅ Система уровней серьезности (high/medium/low)

**Категории подозрительных слов:**
```json
{
  "fraud_keywords": ["мошенничество", "обман", "развод", "халява"],
  "money_laundering_keywords": ["отмывание", "обналичивание"],
  "gambling_keywords": ["ставки", "казино", "покер"],
  "drugs_keywords": ["наркотики", "трава", "спайс"],
  "weapons_keywords": ["оружие", "пистолет", "автомат"],
  "terrorism_keywords": ["терроризм", "теракт", "взрыв"],
  "sanctions_keywords": ["санкции", "эмбарго", "блокировка"]
}
```

**Тестовые результаты:**
- Подозрительное описание: балл 17, найдены слова "халява", "быстрые деньги"
- Нормальное описание: балл 0, паттерны не найдены

**Тестовые результаты:**
- Локальный IP: предупреждение "IP-адрес из неразрешенной страны: LOCAL"
- Подозрительный IP: определение страны "Afghanistan" с высоким баллом
