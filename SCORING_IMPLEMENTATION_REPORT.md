## Реализованные правила скоринга

### 1. AmountLimitRule
- Проверка максимальной суммы транзакции (500k KGS)
- Выявление подозрительно круглых сумм
- Вес: 2.0 (высокий приоритет)

### 2. FrequencyRule  
- Проверка частоты транзакций (10/час, 50/день)
- Анализ паттернов активности
- Вес: 1.5 (средний приоритет)

### 3. GeolocationRule
- Проверка IP-адреса на санкционные страны
- Разрешенные страны: KG, KZ, UZ, TJ, RU, CN
- Вес: 1.0 (стандартный приоритет)

### 4. PhoneNumberRule
- Валидация формата кыргызских номеров
- Выявление подозрительных номеров
- Вес: 1.0 (стандартный приоритет)

### 5. BankCodeRule
- Проверка кодов банков на валидность
- Выявление самоплатежей
- Вес: 1.0 (стандартный приоритет)

### 6. TimeBasedRule
- Проверка времени транзакции (рабочие часы)
- Анализ ночных и выходных транзакций
- Вес: 0.5 (низкий приоритет)
